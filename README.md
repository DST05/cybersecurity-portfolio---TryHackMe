# Cybersecurity Portfolio — TryHackMe

Documentation of my cybersecurity learning journey through the TryHackMe **Pre-Security** and **Cyber Security 101** learning paths.

This repository contains my personal concept summaries, practical activities, screenshots, reflections, and lab documentation as I progress through the learning paths. The purpose of this repository is to demonstrate my learning, development, and practical experience in cybersecurity.

## 📚 Repository Structure

The repository is organised by:

**Learning Path → Module → Room**

This structure allows each room to be documented separately while keeping the overall learning journey organised and easy to navigate.

## 🎯 Purpose

This repository is primarily a personal learning and portfolio project. It documents my progress and helps me demonstrate the knowledge and practical skills I develop throughout my cybersecurity learning journey.

My personal notes in Notion are written in my own words and then condensed into GitHub to focus on the main concepts, activities, and knowledge I have gained.
