# Pre-Security

## Overview

The **Pre-Security** learning path introduces the fundamental concepts and technologies that form cybersecurity foundations.

The course progresses from computer fundamentals through operating systems, software, networking and web technologies before introducing fundamental cybersecurity concepts.

---

## What I Will Learn

Throughout this learning path, I will develop my understanding of:

* Computer hardware and different types of computer systems
* Operating systems and command-line interfaces
* Software, programming and databases
* Networking and how computers communicate
* How the web works
* Virtualisation and cloud computing
* Fundamental cybersecurity concepts, including attacks, defence and cryptography
