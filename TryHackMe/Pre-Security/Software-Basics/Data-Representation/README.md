# Data Representation

## Overview

This room is about representing data using different number systems and converting between decimal, binary and hexadecimal. It also introduces how colours can be represented digitally using RGB values.

## Learning Objectives

* Understand hexadecimal numbers
* Understand binary numbers
* Understand how colours can be represented using RGB
* Understand how different number systems can represent data

## Key Concepts

* **Binary** – A base-2 number system that uses the digits `0` and `1`.
* **Decimal** – A base-10 number system that uses the digits `0` to `9`.
* **Hexadecimal** – A base-16 number system that uses `0–9` and `A–F`.
* **RGB** – A colour representation using red, green and blue values to create different colours.
* **Octal** – A base-8 number system using the digits `0` to `7`. Binary can be grouped into sets of three bits to represent octal values.

## Practical Activities

* Used a converter to convert between hexadecimal, decimal and binary values.
* Used a converter to explore numerical values with and without colour representation.

## Key Takeaways

* Binary uses base 2.
* Octal uses base 8 and can represent groups of 3 bits.
* Hexadecimal uses base 16 and can represent groups of 4 bits.
* RGB values can be used to represent colours digitally.
