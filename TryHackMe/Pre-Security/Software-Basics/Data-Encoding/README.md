# Data Encoding

## Overview

This room is about how computers represent characters and symbols using numerical encodings. It builds on binary, decimal and hexadecimal representation by introducing character encoding standards such as ASCII, ISO encodings and Unicode, including how emojis and characters from different languages are represented.

## Learning Objectives

- Understand how characters are represented using numerical values.
- Understand ASCII and its limitations.
- Understand the purpose of Unicode.
- Understand the differences between UTF-8, UTF-16 and UTF-32.
- Understand how different encodings can cause characters to be displayed incorrectly.

## Key Concepts

- **ASCII** – A character encoding standard that assigns numerical values to English letters, digits, punctuation and control characters.
- **ISO-8859** – A series of character encodings designed to support additional characters and languages beyond the original ASCII character set.
- **Unicode** – A universal character standard that assigns a unique code point to characters from different writing systems.
- **UTF-8** – A Unicode encoding that uses 1 to 4 bytes depending on the character and is widely used on the web.
- **UTF-16** – A Unicode encoding that uses 2 or 4 bytes depending on the character.
- **UTF-32** – A Unicode encoding that uses 4 bytes for every code point.

## Practical Activities

- Used character conversion tools to identify ASCII and Unicode values.
- Converted characters between different numerical representations.
- Explored UTF-8, UTF-16 and UTF-32 representations of characters and emojis.
- Investigated how different encodings can cause characters to be displayed incorrectly.

No significant challenges were encountered in this room. Most of the concepts were already familiar to me from GCSE and A-level Computer Science.

## Key Takeaways

- Characters are represented by numerical values that follow agreed encoding standards.
- ASCII is limited compared with Unicode because it primarily represents a relatively small set of characters.
- Unicode provides a standard for representing characters across different languages, symbols and emojis.
- UTF-8, UTF-16 and UTF-32 are different ways of encoding Unicode characters.

## Reflection

This room was mostly familiar to me because I had already covered many of the concepts through GCSE and A-level Computer Science. The main areas that were newer to me were the ISO encoding concepts and the different UTF encoding formats.

The room helped connect my previous understanding of binary and hexadecimal representation with how computers actually store and display text. It also showed why using consistent character encoding is important when transferring or displaying information.

This is relevant to cybersecurity because incorrectly interpreted or encoded data can affect how information is displayed and processed, while understanding different encodings is also useful when analysing files, network data and web content.
