# Operating System Security

## Overview

This room builds on my previous understanding of operating systems and Linux by introducing the security risks associated with operating systems. It focuses on the CIA Triad, authentication, file permissions, least privilege and malicious software.

## Learning Objectives

- Understand the CIA Triad in relation to operating system security.
- Understand the risks of weak authentication and passwords.
- Understand file permissions and the principle of least privilege.
- Understand how malicious software can affect a system.
- Apply basic Linux commands to investigate a remote system.

## Key Concepts

- **CIA Triad** – Confidentiality, Integrity and Availability are the three fundamental security objectives for protecting information and systems.
- **Authentication** – Verifies the identity of a user before access is provided.
- **Least Privilege** – Users should only have the permissions necessary to perform their tasks.
- **File Permissions** – Control who can access or modify files and directories.
- **Malicious Software** – Software that can compromise confidentiality, integrity or availability.
- **SSH** – Allows secure remote access to a system through the command line.

## Practical Activities

- Connected to a remote Linux machine using SSH.
- Identified users and examined files using Linux commands.
- Investigated command history.
- Explored how weak authentication and permissions can lead to increased system access.

## Key Takeaways

- Operating system security builds on understanding how users, files and processes are managed.
- Weak passwords and excessive permissions can increase the risk of unauthorised access.
- The CIA Triad provides a useful framework for understanding the security impact of attacks.
- Linux command-line skills can be applied when investigating remote systems.
