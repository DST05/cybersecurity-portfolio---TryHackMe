# Windows CLI Basics

## Overview

This room introduced the Windows Command Prompt and how it can be used to navigate the file system, locate and read files, and gather basic system and network information. The practical activities involved using the Windows CLI to investigate a Windows machine without relying on the graphical interface.

## Learning Objectives

- Understand the purpose of the Windows command line.
- Navigate the Windows file system using Command Prompt.
- Find and read files using the command line.
- Gather basic system and network information.
- Become more comfortable using the Windows CLI.

## Key Concepts

- **`cd`** – Displays the current directory or changes to another directory.
- **`dir`** – Lists files and directories in the current location.
- **`dir /a`** – Displays files and directories, including hidden items.
- **`dir /s`** – Searches through subdirectories for a specified file.
- **`type`** – Displays the contents of a text file.
- **`whoami`** – Displays the account currently being used.
- **`hostname`** – Displays the name of the computer.
- **`systeminfo`** – Displays detailed information about the Windows system.
- **`ipconfig`** – Displays basic network configuration information.

## Practical Activities

- Navigated the Windows file system using Command Prompt.
- Located a file when only its filename was provided.
- Read the contents of a file through the terminal.
- Checked the current user and computer name.
- Gathered Windows system information.
- Checked basic network configuration.

## Challenges Encountered

The main challenge I encountered was navigating to the file using a long command line with very little room for errors. It took me around 30 minutes to identify what was wrong because of a combination of an unnecessary character, incorrect spacing, and a spelling mistake.

This showed me how important accuracy and attention to detail are when working with the Windows command line, as even a small error can prevent a command from working correctly.

## Key Takeaways

- The Windows CLI provides another way to interact with and investigate a system without relying on the graphical interface.
- Windows and Linux use different commands and syntax for similar tasks.
- Commands such as `dir`, `type`, `systeminfo` and `ipconfig` can quickly provide useful information about a Windows system.
- Accuracy and attention to detail are important when working with command-line tools.
- Command-line skills are useful in cybersecurity because analysts may need to investigate systems quickly without relying on graphical tools.

## Reflection

Unlike Linux CLI Basics, I found most of this room easier because I had already developed an understanding of command-line interfaces. However, the file navigation challenge was more difficult than expected because the command was long and required complete accuracy.

Spending around 30 minutes troubleshooting a small mistake reinforced that command-line work requires precision, particularly when working with long commands. It also helped me become more comfortable with identifying and correcting syntax, spacing and spelling errors rather than immediately assuming that the command itself was wrong.

The room also helped reinforce that Windows and Linux use different commands and syntax to perform similar tasks. This is useful for cybersecurity because both operating systems are commonly encountered during system administration, troubleshooting and security investigations.
