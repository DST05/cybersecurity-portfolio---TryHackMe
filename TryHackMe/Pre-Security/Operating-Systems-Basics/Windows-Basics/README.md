# Windows Basics

## Overview

This room provided a practical introduction to the Windows operating system, focusing on navigating the Windows interface, managing files and applications, viewing system information, and using built-in security tools.

## Learning Objectives

- Navigate the Windows desktop and File Explorer
- Understand basic Windows system management
- Use Task Manager to monitor system activity
- Understand basic Windows security features

## Key Concepts

- **File Explorer** – Used to navigate and manage files and folders.
- **Task Manager** – Used to monitor processes and system resource usage.
- **Windows Security** – Provides built-in protection against threats.
- **Windows Defender Firewall** – Controls network traffic to and from the system.
- **User Permissions** – Determine what actions an account can perform.

## Practical Activities

- Navigated a Windows Server 2019 environment
- Checked system information and user details
- Managed files and applications
- Used Task Manager
- Performed a Windows Security scan
- Examined Windows Defender Firewall settings

## Challenges Encountered

None. This room was very straightforward for me, as I have used Windows extensively since 2014.

## Key Takeaways

- Windows provides several built-in tools for system administration and security.
- Understanding Windows administration is important for cybersecurity because Windows is widely used in organisations.
- Security tools such as antivirus, firewalls, and user permissions form part of the system's basic defensive controls.

## Reflection

Unlike the other rooms, this room was mainly a reinforcement activity for me rather than introducing significant new concepts. The practical activities provided a quick opportunity to reinforce where common system information and security tools are located.

The room also reinforced that Linux is not the only operating system used in cybersecurity. Although Linux is widely used in many cybersecurity environments, Windows remains highly relevant due to its widespread use in organisations and its importance in system administration and security.
