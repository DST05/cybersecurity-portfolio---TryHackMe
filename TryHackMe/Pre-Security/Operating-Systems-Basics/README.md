# Operating Systems Basics

## Overview

This module introduced the fundamentals of operating systems and how they manage computer hardware, software, users and system resources. It covered Windows and Linux environments, command-line interfaces, system management and the security principles used to protect operating systems.

## Rooms Completed

- [**Operating Systems: Introduction**](./Operating-Systems-Introduction/README.md) 
- [**Windows Basics**](./Windows-Basics/README.md) 
- [**Linux CLI Basics**](./Linux-CLI-Basics/README.md) 
- [**Windows CLI Basics**](./Windows-CLI-Basics/README.md)
- [**Operating System Security**](./Operating-System-Security/README.md) 

## Skills Developed

- Understanding the role and responsibilities of operating systems.
- Navigating Windows and Linux environments.
- Using graphical and command-line interfaces.
- Using basic Linux and Windows CLI commands to navigate files and gather system information.
- Understanding user accounts, permissions and authentication.
- Understanding the CIA Triad and its relevance to operating system security.
- Recognising common operating system security risks.
- Developing familiarity with Windows and Linux system administration.

## Practical Experience

- Used Ubuntu Linux and Windows Server environments through TryHackMe lab machines.
- Navigated files and directories using graphical interfaces and command-line tools.
- Used Linux commands such as `ls`, `cat`, `whoami`, `find` and `uname`.
- Used Windows commands such as `dir`, `cd`, `type`, `systeminfo`, `hostname` and `ipconfig`.
- Investigated system and network information.
- Connected to a remote Linux system using SSH.
- Investigated users, files and command history.
- Used Windows Security and Windows Defender Firewall.
- Troubleshot command-line errors and improved accuracy when entering commands.

## Reflection

This module strengthened my existing understanding of operating systems while giving me more practical experience with both Windows and Linux. Much of the introductory theory was familiar from GCSE and A-level Computer Science, but the practical activities provided opportunities to apply that knowledge in different environments.

The Linux CLI rooms were particularly valuable because they pushed me outside my usual comfort zone and required greater accuracy when working with commands. I have continued practising these skills using my own Kali Linux virtual machine to improve my familiarity with Linux commands and syntax.

The module also helped connect operating system knowledge with cybersecurity. Understanding how operating systems manage users, permissions, files, processes and system resources provides an important foundation for investigating and securing systems.
