# Linux CLI Basics

## Overview

This room is about learning essential command lines that are used in Linux, in this case, finding information inside a hidden file in a directory in the Linux terminal. We also went through command lines that helped us find key information about the virtual machine, such as `cat`, `whoami` and more.

## Learning Objectives

- Understand the purpose of using the Linux Terminal.
- Navigate the Linux Terminal to use basic command instructions and become comfortable using the Linux Terminal.

## Key Concepts

- **`cat`** - Used to read the contents of a file.
- **`ls`** - Used to list the files and folders of the operating system.
- **`whoami`** - Shows the current username of the operating system.
- **`uname -a`** - Displays comprehensive information about the system and its kernel.
- **`df -h`** - Displays information about the available and used disk space in a human-readable format.
- **`cd etc/`** - Used to change the current directory to the `etc` directory.
- **`~$ find ~ -name <filename>`** - Used to search for a specific file by its name within the home directory.

## Practical Activities

- Finding/reading a text message in the terminal through a hidden file.
- Checking system information in the Linux terminal.

## Challenges Encountered

There have been challenges in this room, especially with the mini challenge where, in a similar scenario to an example demonstration, we have to independently find a file with only a file name to find the message with the flag to confirm that we have found the file, with only very few clues to figure out the hidden file. Another challenge I have encountered is that concise information and precision are needed on the Linux command line to minimise spelling mistakes and to type long command lines without full clarity on what will happen next.


## Key Takeaways

- Linux command lines can be used to navigate the file system and find specific files and information.
- Different Linux commands have different purposes, such as reading files, finding users, and checking system information.
- Accuracy and precision are important when using the Linux command line.
- Repeated practice is important for remembering Linux command syntax and its uses.
