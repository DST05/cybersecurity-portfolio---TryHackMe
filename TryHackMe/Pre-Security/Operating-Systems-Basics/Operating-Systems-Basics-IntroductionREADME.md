# Operating Systems: Introduction

## Overview

This room introduces operating systems, including the different types used across computers, mobile devices and embedded systems such as TVs and washing machines. It covers the main responsibilities of an operating system, basic security concepts and the difference between user space and kernel space.

The practical activity involved using an Ubuntu Linux environment to complete basic tasks, such as checking system information and navigating the file system.

---

## Learning Objectives

* Understand what an operating system is and the role it plays.
* Explain the core responsibilities of an operating system.
* Identify common operating system types and their typical uses.
* Understand basic operating system security concepts.
* Practise interacting with an operating system to gather system information.

---

## Key Concepts

* **Operating System (OS)** – Software that manages a computer's hardware and provides services for applications and users.
* **Kernel Space** – The part of the operating system where core system functions and hardware management take place.
* **User Space** – The area where applications and user processes operate without directly accessing critical system resources.
* **CLI** – A text-based interface used to interact with an operating system through commands.
* **GUI** – A graphical interface that allows users to interact with an operating system using visual elements.
* **File System Management** – Organising and managing files and directories.
* **User Management** – Managing user accounts and their access to the system.

---

## Practical Activities

* Used an Ubuntu MATE Linux environment to check information about the system, including the operating system version and available memory.
* Navigated the file system and examined file paths to understand how files are organised and identified.
* Used the graphical user interface to locate system information and files.

## Challenges Encountered

I did not encounter any significant difficulties with the concepts themselves, as most of the material was familiar from Computer Science.

The main challenge was navigating Linux, particularly finding specific information through the settings and file explorer because I have limited experience using Linux compared with other operating systems.

---

## Key Takeaways

* Operating systems are not limited to traditional computers; tablets and smartphones are also used in many everyday and embedded devices.
* Operating systems manage hardware, software, files, processes, users and system resources.
* Linux provides a different environment and interface from the operating systems I am more familiar with.
* Understanding operating systems is important for understanding how computers can be secured.

---

## Reflection

Most of the concepts in this room were already familiar to me from A-Level Computer Science and, in some cases, GCSE Computer Science. As a result, I did not find the theoretical content particularly challenging.

The practical activity was more useful because it required me to work with Ubuntu Linux, which I rarely use. Finding system information and navigating the Linux file system gave me practical experience outside of the operating systems I normally use.

This is relevant to cybersecurity because operating systems manage the hardware, applications, users and permissions that security professionals need to protect. Developing familiarity with different operating systems, particularly Linux, will therefore be useful for future cybersecurity labs and practical work.
