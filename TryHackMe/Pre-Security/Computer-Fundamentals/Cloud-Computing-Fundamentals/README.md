# Cloud Computing Fundamentals

## Overview

This room introduces cloud computing and how organisations can access computing resources without having to own and maintain all of the physical infrastructure themselves. It covers cloud service models, different cloud types and how major companies use cloud computing.

## Learning Objectives

- What is cloud computing?
- Understand the different cloud service models: IaaS, PaaS and SaaS.
- Understand different cloud types: Public, Private and Hybrid.
- Understand how major companies use cloud computing.

## Key Concepts

- IaaS – Infrastructure as a Service; provides computing infrastructure such as virtual machines, storage and networking.
- PaaS – Platform as a Service; provides an environment for developing and deploying applications.
- SaaS – Software as a Service; provides complete software applications over the internet.
- Cloud Computing – Accessing computing resources and services over the internet.
- Cloud Vendors – Companies that provide cloud computing services.

## Practical Activities

- Used a simulated cloud interface based on an AWS platform.
- Created and managed virtual machines based on resource and cost constraints.
- Tested how stopping unused machines affected the overall cost.

## Key Takeaways

- Cloud computing allows organisations to access computing resources without owning all of the underlying infrastructure.
- Different cloud deployment types provide different levels of control and accessibility.
- Cloud resources can be scaled according to demand.
- Cloud computing can be managed according to resource requirements and cost.

## Reflection

For this specific topic, I already had a good grasp of cloud computing from GCSE and A-level Computer Science. However, I learned more about the different cloud service models and deployment types, particularly how they provide different levels of control and responsibility.

The practical activity also helped me understand how cloud resources can be created, managed and adjusted according to requirements and cost.

Cloud computing is important to cybersecurity because many modern systems and applications operate within cloud environments. Understanding how cloud infrastructure works provides a foundation for understanding how these environments can be secured.
