# Computer Fundamentals

## Overview

This module introduces the fundamental concepts behind modern computer systems and how they are used to provide services and infrastructure. It covers computer hardware, different types of computers, client-server systems, virtualisation and cloud computing.

## Skills Developed

- Understanding computer hardware and its components
- Understanding different types of computer systems
- Understanding the client-server model and basic network services
- Understanding virtual machines, hypervisors and containers
- Understanding the fundamentals of cloud computing
- Understanding how modern computing infrastructure supports applications and services

## Reflection

This module reinforced my existing knowledge of computer fundamentals while introducing concepts beyond what I had previously studied, particularly client-server architecture, virtualisation, containers and cloud computing.

Understanding these areas provides an important foundation for cybersecurity because security professionals need to understand the systems and infrastructure they are protecting. The knowledge gained from this module will support my learning of operating systems, networking and cybersecurity concepts in the following modules.
